# LidarVerse project page

Anonymous project page for **Into the LidarVerse: A Real-Time Unified LiDAR World Model Across Tasks and Sensors**.

## Run

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

## Update

- Replace capability media under `assets/` with final videos or figures. Cross-sensor media lives under `assets/cross-sensor/`.
- Update result values in the `tables` object in `script.js`.
- Replace the `TBD` material and PM fields when links and ownership are final.
